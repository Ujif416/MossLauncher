MossLauncher 1.0.3 — Windows x64

УСТАНОВКА
Запустите MossLauncher-Setup-1.0.3-x64.exe. Установка выполняется в отдельную папку приложения; выбор произвольной папки отключён.
Не используйте старый Setup 1.0.0: при выборе папки исходников его удаление могло затронуть проект.
Новый установщик и деинсталлятор останавливаются, если целевая папка содержит проект.

БЕЗ УСТАНОВКИ
MossLauncher-Portable-1.0.3-x64.exe запускается без мастера установки.
Настройки, аккаунты и игры по умолчанию находятся в %APPDATA%\mosslauncher.
Это переносимый исполняемый файл, но профиль хранится на компьютере.

ВЕРСИИ И МОДЫ
Для NeoForge выберите Minecraft и нужную версию загрузчика. Базовая игра скачивается автоматически.
Служебные зависимости и незавершённые установки не показываются как готовые версии.
После установки выбирается версия с загрузчиком.
Во вкладке «Моды» выберите целевую версию. Путь к её модам показан под списком.

ВХОД
Microsoft-вход показывает код для страницы Microsoft. Для игры требуется Minecraft Java Edition на аккаунте.
Выдача кода и отмена проверены; полный вход требует подтверждения владельцем аккаунта.

ПРОВЕРКА ФАЙЛОВ
SHA256SUMS.txt содержит контрольные суммы. Подпись издателя не настроена.
TEST-REPORT.md описывает проверки и ограничения. THIRD-PARTY-NOTICES.txt содержит уведомления зависимостей.

СКИНЫ
Аккаунты → Загрузить скин → Выбрать PNG → Classic/Slim → Применить к аккаунту.
Скин меняется в официальном профиле Minecraft Java Edition. После смены перезапустите игру.
Кнопка SkinsRestorer копирует команду для чата сервера; сервер должен разрешать смену скина.
Обновить скин загружает актуальные сведения профиля, если скин менялся вне лаунчера.

СКИНЫ ОФЛАЙН-АККАУНТОВ
Аккаунты → Загрузить скин → PNG → Classic/Slim → Загрузить на MineSkin. Файл отправляется внешнему сервису и становится доступен как публичная текстура.
Скопируйте показанную команду /skin url и выполните её в чате каждого нужного сервера со SkinsRestorer. Требуется разрешение skinsrestorer.command.set.url.
Скин сохраняется у офлайн-аккаунта и отображается в лаунчере. В одиночной игре и на серверах без поддержки скинов он автоматически не применяется.
Если MineSkin требует авторизацию или исчерпан гостевой лимит, используйте личный API-ключ с account.mineskin.org/keys. Ключ вводится для загрузки и не сохраняется лаунчером.
