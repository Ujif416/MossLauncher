# Проверки MossLauncher — 14 ноября 2026

## Прогресс и просмотр модов сборки — 1.0.6, 16 ноября 2026

- На основе исходников 1.0.5: изменены только прогресс загрузки сборок, экран сборок и IPC для чтения их модов. Исходники до изменений сохранены в build/modpack-change-baseline; прочие модули совпадают побайтово.
- GitHub, CurseForge и Modrinth передают фактические байты скачанного архива и счётчики обработанных файлов. Процент относится к текущему этапу. При неизвестном размере архива показываются полученные байты и индикатор активности.
- Полоса и карточки сохраняют DOM. В реальном renderer Electron проверены 100 событий через IPC, смена этапов, геометрия всех кнопок, фокус и отсутствие повторного запуска анимаций кнопок. Существующие кнопки главного экрана также сохраняются при прогрессе сборки.
- Кнопка «Моды» читает фактические .jar и .jar.disabled из папки выбранной сборки, независимо от активной версии игры. Проверены 162 файла, поиск без учёта регистра, прокрутка, размеры, отключённые моды, пустая папка, недопустимые имена и закрытие окна при смене вкладки. Поиск и фокус сохраняются во время загрузки.
- Проверены загрузки с известным/неизвестным размером, перенаправление, параллельная загрузка в один путь, оборванный поток, неверный SHA-1 и очистка .part. Сценарии всех трёх источников прошли на локальном HTTP-сервере с тестовыми архивами и ответами каталогов.
- Проверки прошли из исходников и из готового release/1.0.6/win-unpacked/resources/app.asar. Отчёты: build/modpacks-check.log и build/modpacks-release-check.log; повтор: electron tools/modpacks-check.cjs --release.
- В этой проверке не скачивались реальные большие сборки из интернета, не запускалась игра и не менялись пользовательские профили. Настройки защиты установщика не изменены; установка/удаление Setup повторно не выполнялись.

Проверки выполняются в `.functional-check` и `.smoke-data`. Пользовательские миры и сборки не используются.

Для Fabric/Quilt/Forge проверены каталоги, но полный запуск этих загрузчиков в этой сессии не выполнялся. Нативные диалоги выбора файла и все сочетания параметров окна не покрыты автоматическим тестом.

## Изменения поведения

- Главная ошибка .jar.part устранена исправлением классификаторов, уникальными временными файлами и последовательной записью в одинаковый destination.
- Поиск модов: отдельный источник, 20 результатов на страницу, Назад/Далее, число страниц; новый запрос или фильтр сбрасывает страницу, устаревшие ответы отбрасываются.
- При установке загрузчика открывается список конкретных совместимых версий; выбранное значение передаётся установщику и проверяется на стороне main.
- Игровые папки теперь находятся в `<gameDir>/instances/<versionId>`; активные моды копируются из `<gameDir>/mods/<versionId>` перед запуском. Существующие миры автоматически не перемещаются.
- Учитываются дополнительные аргументы JVM и настройки сворачивания/скрытия лаунчера и открытия журнала.

## Моды и сборки — версия 1.0.4, 15 ноября 2026

- CurseForge моды и сборки работают без API-ключа через cfwidget (`api.cfwidget.com`): список файлов, метаданные версий, точные имена для ForgeCDN. Веб-endpoint `www.curseforge.com/api/v1` закрыт Cloudflare (403) и оставлен только как fallback.
- Поддерживаются три источника сборок: GitHub (owner/repo), CurseForge (cf:slug), Modrinth (mr:slug). У каждой карточки сборки есть выбор версии (файлы CF / версии Modrinth / ветки GitHub), прогресс синхронизации и кнопка «Играть», которая подбирает установленную версию игры с нужным загрузчиком.
- Исправлена ошибка `Error invoking remote method 'versions:loaders': AggregateError` — обработчик `LIST_LOADERS` обёрнут в `wrap()`, ошибки попадают в журнал сессии вместо падения IPC.
- Добавлен журнал ошибок сессии (in-memory, 500 записей): вкладка «Логи» → «Ошибки сессии». Все IPC-обработчики модов и сборок обёрнуты в `wrap()` с автоматическим логированием.
- Установленные моды получили кнопку «Проверить обновления» — для каждого мода с source=modrinth/curseforge сравнивается текущая версия с последней доступной, при наличии обновления показывается бейдж «Обновление».
- Диалог выбора версии файла мода: для Modrinth подгружаются версии с файлами, для CurseForge используется список из cfwidget. Фильтры по версии MC и типу (release/beta/alpha).
- Сборка привязывается к инстансу игры: `.moss-pack-link` в `instances/<versionId>` указывает на папку сборки, при запуске файлы копируются в инстанс с трекингом `.moss-managed-pack.json`. Кнопка «Играть» у сборки запускает игру с привязанной сборкой.
- Проверены синтаксис всех изменённых модулей (`node --check`), отрисовка всех 7 вкладок в собранном приложении, пагинация модов Modrinth, сортировка CF-файлов по id (монотонный рост), обработка AggregateError в журнале.
- Ограничения: поиск CurseForge без ключа невозможен — только вставка ссылки/slug. Полный запуск сборок с модами на реальном инстансе не проверялся (требуется интерактивная игра). NeoForge Maven недоступен из тестовой сети (ETIMEDOUT), поэтому выбор версий NeoForge в диалоге установки не проверен в этой сессии.
- Отчёты: build-smoke-report.log (все вкладки отрисованы, пагинация модов), build/functional-check.log (10 PASS / 1 сетевой FAIL по NeoForge Maven), build/regression-check.log (стабильность UI, каталоги загрузчиков).
