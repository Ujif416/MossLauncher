# MossLauncher

Готовый установщик и portable для распространения: `release/1.0.0/`.
Сборка релиза: `npm run build:release`, затем `npm run release:prepare`.
Инструкции выпуска: distribution/RELEASE-CHECKLIST.md.

Minecraft Java Edition launcher для Windows x64. Интерфейс использует assets/mosslauncher-complete; главный экран ориентирован на screens/home-screen.png.

## Запуск и сборка

- Установите Node.js и выполните `npm ci`.
- `npm start` запускает приложение из исходников.
- `npm run build:portable` собирает portable EXE; `npm run build` — установщик NSIS.
- Готовый portable файл: dist/MossLauncher.exe.

Добавьте аккаунт на странице «Аккаунты», установите версию в каталоге «Версии», выберите её на главной и запустите. Для модов установите подходящий загрузчик. CurseForge требует собственного API-ключа в настройках. Microsoft-вход требует действий пользователя в браузере и доступа аккаунта к Minecraft. Offline-аккаунт предназначен для локальной игры и не даёт доступ к серверам с проверкой лицензии.

В настройках доступны память, Java, папка игры и интеграции. Java можно установить через Adoptium. Сборки GitHub синхронизируются со своим каталогом через codeload.

Данные находятся в Electron userData (обычно `%APPDATA%/mosslauncher`); конфигурация config.json, аккаунты accounts.json, диагностика logs/launcher.log. Секреты и аккаунты не отправляйте вместе с отчётами.

## Проверка

`node_modules/electron/dist/electron.exe tools/smoke.cjs` проверяет семь экранов с отдельными данными .smoke-data и пишет build-smoke-report.log; скриншоты — build/home-smoke.png и build/settings-smoke.png. Проверка подтвердила отрисовку экранов и загрузку изображений. Полный запуск Minecraft, Microsoft-вход, CurseForge и синхронизация реальной сборки требуют отдельной интеграционной проверки; сетевой запрос каталога в этой сессии завершился socket hang up. Не следует считать эти сценарии подтверждёнными по одной проверке интерфейса.


## Обновление: страницы модов и версии загрузчиков

На странице модов выберите источник и фильтр загрузчика; результаты разбиты на страницы по 20 элементов. При установке Minecraft с загрузчиком появится диалог выбора его конкретной версии, включая NeoForge 21.1.265/21.1.266.

Актуальные результаты проверок — TEST-REPORT.md (они уточняют первоначальный раздел проверки выше). Реальные установки Java 21 и NeoForge 21.1.265 выполнены; Vanilla 1.21.1 и NeoForge дошли до инициализации графического интерфейса. Microsoft OAuth и CurseForge с ключом требуют пользовательского участия.

Игровые данные каждого профиля теперь находятся в `<gameDir>/instances/<versionId>`; ранее созданные миры не перемещаются. Исходный набор модов хранится в `<gameDir>/mods/<versionId>` и подготавливается перед запуском.
